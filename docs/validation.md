# 验证状态与 macOS 验收

## 当前已执行

- Swift 6.1.3 Linux 工具链发布签名验证成功。
- `MindMapCore` 编译成功，31 项 Swift Testing 用例通过。
- 两种布局各 1001 个节点的矩形不重叠、端点与包围盒检查通过。
- App 源文件 Swift 语法解析和构建脚本 Bash 语法检查通过。
- 8 个启动脚本模拟用例通过，覆盖构建失败、取消/超时退出、仅构建、成功替换及替换/恢复失败；没有操作真实应用。
- 7111 节点深树可打开、保存、重开并改名；10000 节点及深度 128 的 Markdown 往返与 Tab 文本保留通过。
- 独立 Linux `swiftc -O` 基准中，10000 节点的旧折叠按钮扫描约 1.33 秒，新几何扫描平均约 0.007 毫秒/次（1000 次查询）；不包含 AppKit 事件、布局或绘制。
- Linux 执行 GUI 构建入口时会明确提示需要 macOS，并以非零状态退出。
- 9 个开发预发布模拟用例通过，覆盖分支/事件限制、产物完整性、精确提交、草稿恢复、已发布版本保护和上传失败不公开。

这不是 macOS 应用编译或运行证明。下表全部需要在 Mac 上执行，尚未由当前 Linux 工作区验证。

## Mac 上的必要检查

先运行 `swift test`（31 项内核 + 9 项原生测试）和 `bash script/tests/build_and_run_tests.sh`，再运行 `./script/build_and_run.sh --verify`。Mac CI 另外运行打包产物的冷启动主窗口检查。

| 操作 | 预期 |
| --- | --- |
| 从应用图标普通启动，关闭全部窗口后再次点击 Dock | 显示 pmind 主界面，不自动弹出打开文件面板 |
| 主界面新建、打开、取消打开及选择最近文件 | 新建为空白导图；仅点击打开才显示文件面板；取消仍留在主界面；最近文件可打开，失效文件报错 |
| 编辑中选择“文件 → 显示主界面”，或从 Finder 双击文件 | 主界面复用同一个窗口；已有文档不受影响；Finder 文件仍交给文档编辑窗口 |
| 新建两个文档，分别编辑并撤销 | 内容、历史和选区互不影响 |
| Tab/Return、工具栏添加子/同级主题 | 标题立即可编辑，中心主题没有同级/删除操作 |
| 标题尚在编辑时用 ⌘Return / ⇧⌘Return 新增主题 | 先保留旧标题，再进入新主题编辑；撤销重做与窗口隔离正确 |
| 中文输入法、换行、空标题、长标题 | 输入无中断；文字不超出主题；Escape 取消编辑 |
| 文字框内 Delete、⌘C/⌘V | 只编辑文字，不删除或复制整棵主题 |
| 跨分支拖拽、同级前后插入 | 顺序与层级正确；拖进后代不改变文档 |
| 连续撤销重做、新增、删除、移动、折叠 | 内容与选区正确恢复，空操作不占历史 |
| 大纲折叠/选中、搜索折叠分支中的备注 | 与画布一致，搜索可展开祖先并定位 |
| 缩放、平移、定位中心、适应窗口 | 定位中心不改变缩放；适应窗口不包含空白工作区 |
| 编辑标题后立刻 ⌘S、关闭并重开 | 最新文字已保存；无路径文档出现系统保存面板 |
| 修改后关闭窗口和退出 | 系统保留/询问未保存修改，不静默丢弃 |
| 有未保存文档时重新运行构建启动脚本，取消退出 | 旧应用继续运行，旧 Bundle 不被覆盖，新实例不启动 |
| `.pmind` 打开、另存为、损坏文件、未来版本 | 正常往返；错误明确，不静默覆盖原文件 |
| 导出中文、多行文字、备注标识的 PNG/PDF | 正向文字、无裁切；折叠内容隐藏；无选区控制框 |
| 1000 节点示例与深/宽分支 | 无重叠；记录实际布局、拖动、缩放体验 |
| 浅色/深色与 VoiceOver | 系统外观正常；大纲、菜单和按钮可操作 |
