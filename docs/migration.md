# 从旧网站迁移

新版是独立的 macOS 文档应用，不连接旧 Go 服务或数据库，也不直接打开旧 `.wmind`、XMind 或数据库备份。

1. 在仍可运行的旧版本中打开导图，导出 Markdown。旧版本源码保留在原生重构之前的 Git 历史中。
2. 在新版使用“文件 → 打开”选择 `.md` 文件。
3. 检查主题层级和文本，然后另存为新的 `.pmind` 文件。

Markdown 可迁移主题层级和可表达的文字；旧版的概要、联系线、边界、图片、附件、公式、样式、多画布与在线分享配置不迁移。请保留原 `.wmind`、数据库和文件备份，新版不会覆盖它们。

重构只删除了 Git 跟踪的旧代码和部署文件。工作区已有的忽略文件（如 `backend/.env`、`backend/data`、上传目录、`frontend/node_modules`）保留，避免丢失本地数据。这些目录不属于新工程，也不会被新版读取或启动。确认已备份且不再需要后可自行清理。
